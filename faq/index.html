What is Text by Mail?

Text by Mail is a Yellow Letter HQ service that prints a unique code on your mail piece. The person who receives the mail can text that code to get offer information about the property and start a conversation with you. You then receive their property address and phone number so you can follow up.

How it works

  1. A unique code is printed on your mail piece.
  2. The recipient texts that code to get offer information on the subject property and start a conversation.
  3. You receive the recipient's property address and phone number so you can follow up with an offer.

To use the text notifications (short code 81363, which is advertised on the mailing):

  • Text START to 81363 to opt in and receive notification messages.
  • Text STOP to 81363 to cancel. We will confirm that you have been unsubscribed, and you will no longer receive SMS messages from us.
  • Text HELP to 81363 for instructions.

Message and data rates may apply, and message frequency can vary. Details are in our Terms.

What is the difference between First Class and Standard Mail?
  • First Class costs more. It is forwarded if the recipient moved and filed a change of address, and undeliverable pieces come back to you. It's the only postage that gives you return mail.
  • Standard Mail is bulk mail with a lower postage rate. It isn't forwarded the same way, there is no return mail, and it doesn't arrive on a consistent weekday.

Lists & Data / Budget Maximizer

What is the Budget Maximizer?

The Budget Maximizer is not a separate tool. It is the list-upload process on every order page, and it is included with every list you upload.

When you upload a list, the system automatically:

  • Removes undeliverable addresses and records that are missing a complete mailing address
  • Removes duplicate property addresses
  • Combines several small lists into one campaign, so you can reach a better quantity price
  • Standardizes addresses and runs NCOA, CASS, and Delivery Point Verification
  • Turns trust names like "Ontiveros Trust 1997" into "Ontiveros Family"
  • Fills in "Property Owner" when the name is blank
  • Remembers your column headers and auto-matches them
  • Gives you a copy of the combined list

You pay at checkout only for the records that will actually be mailed. If you have already paid and the final clean count is lower, we credit the difference as store credit.

What is your refund and cancellation policy?

The default is store credit toward a future order, not a cash refund.

  • Canceled before printing: full store credit.
  • Already printed: a disposal fee may apply, and the rest is credited. Per piece, that fee is 5 cents for a quarter-page postcard, 8 cents for a half-page postcard, 11 cents for a jumbo postcard, 10 cents for a letter or pressure-sealed piece with no stamp, 17 cents with a Standard stamp, and 25 cents with a First Class stamp.
  • Unapproved for 45 days: canceled automatically with full store credit.

Skip tracing, memberships, and ListSource accounts aren't refunded or prorated. See our Terms.
